How to read the evidence scores

Both scores use 0–4: unsupported, weak, moderate, strong, very strong. They describe evidence, not measured probabilities.

Attribution: support for assigning responsibility to HSBC or a supplier. UNCERTAIN uses 0–2 and waits for a definite human classification.

Engagement: support for a particular engagement in the supplied candidates. Name similarity alone does not establish the correct engagement. A saved model default still needs your explicit approval.
